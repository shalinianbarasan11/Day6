### Explain about class and objects
    Java is associated with classes and objects along with the attributes and methods.
    class: A class is a blueprint or template for creating an objects, its define the structure with  attributes(such as fiels,data) and methods(such as behaviour or actions).
    A class related variables and methods into a single unit, acting as a template without occupying memory until instantiated.
    class declared once and reuse the code.
    To create a class, use the keyword class.
    Objects: An objects is an instance of a class. To create an object use the new keyword. Each object has its own state(value)  and identity, stored on the heap memory.
    you can create multiple objects from one class.
